Grade 8 Mathematics — Representing Square Roots & Approximating Irrationals

📐 Theory Compendium: Approximating Square Roots & Irrational Numbers

An irrational number is a non-terminating, non-repeating real number. Because square roots of non-perfect squares cannot be written as exact fractions, we use rational approximations by bracketing them between consecutive integers and successive decimal tenths.

1. Integer Bracketing for Square Roots

To find the whole numbers between which \(\sqrt{N}\) lies, find consecutive integer perfect squares \(a^2\) and \((a+1)^2\) such that:

\[a^2 < N < (a+1)^2 \implies a < \sqrt{N} < a+1\]
Example: For \(\sqrt{46}\): \[36 < 46 < 49 \implies 6^2 < 46 < 7^2 \implies 6 < \sqrt{46} < 7\]

2. Refining Approximations to the Nearest Tenth

Test tenths between \(a\) and \(a+1\) by squaring decimal tenths:

  • Compare distance to the bounds: \(46\) is closer to \(49\) than \(36\).
  • Test \(6.7^2 = 44.89\), \(6.8^2 = 46.24\).
  • Since \(46.24\) is only \(0.24\) away from \(46\), \(\sqrt{46} \approx 6.8\).

3. Negative Radicals on the Number Line

The negative square root \(-\sqrt{N}\) is the reflection across zero of \(\sqrt{N}\):

\[a < \sqrt{N} < b \implies -b < -\sqrt{N} < -a\]
Example: For \(-\sqrt{14}\): \[9 < 14 < 16 \implies 3 < \sqrt{14} < 4 \implies -4 < -\sqrt{14} < -3\]

4. Comparing and Ordering Real Numbers

To compare radicals with integers or algebraic constants (\(\pi \approx 3.14159\), \(\pi^2 \approx 9.87\)):

  • Method 1 (Squaring): To compare \(\sqrt{29}\) and \(5.4\), square both: \((\sqrt{29})^2 = 29\), \(5.4^2 = 29.16\). Since \(29 < 29.16\), \(\sqrt{29} < 5.4\).
  • Method 2 (Area Inversion): For square of area \(A = 97\text{ cm}^2\), side \(s = \sqrt{97} \approx 9.849\text{ cm}\).
